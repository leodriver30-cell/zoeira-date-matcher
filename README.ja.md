## 📖 はじめに（どんなアプリ？）

**「いたずら＆デートプランナー」**は、友達と笑い合ったり、好きな人をスマートにデートに誘ったりできるWebアプリケーションです。

一番のポイントは、**「いいえ」を押そうとしてもボタンが逃げてしまい、最後は絶対に「はい」しか選べなくなる**ことです！🐱💨

このアプリには、大きく分けて**2つのモード**があります：

1. **😂 友達へのいたずらモード**：
   面白い質問（例：「私にご飯をおごってくれますか？」）を作って友達に送るモードです。「いいえ」ボタンが画面中を**7回**逃げ回り、**8回目**に「はい」ボタンの後ろにすっぽり隠れて完全に消えてしまいます（押せなくなります）！最後は「はい」を押すしかありません。
2. **💖 ロマンチックデートモード**：
   好きな人の名前を入れた専用リンクを作り、最大**90日先（約3ヶ月前）**までの日程から**最大10日間の候補日**と**正確な3時間の時間枠**（例：`19:00〜22:00`）を選んでもらうモードです。月別切り替えタブ付きで、日本でよくある1〜2ヶ月前の事前約束にも最適です。

## ✨ 主な機能

### 😂 1. いたずらモード：7回逃走＆「はい」の背後に隠れるギミック
- **7回逃げる「いいえ」ボタン**：相手が「いいえ」を押そうとするたびに、ボタンが素早く別の場所に逃げます。
- **8回目の完全隠蔽**：「いいえ」ボタンが「はい」ボタンの後ろにスライドして縮小し、完全に透明・無効化されます（赤い端っこも一切はみ出ません）。
- **回数に応じた楽しい煽りセリフ**：「いいえを押そうとしても無駄ですよ！😂」など、セリフがどんどん変化します。

### 🐱 2. いたずら子猫のボタン泥棒（デートモード演出）
- デートモードの質問では、いたずら子猫（`🐈`）が飛び降りてきて「『いいえ』はボクがもらったにゃ！🐾」とボタンを盗んで画面外へ走り去ります。
- その後「はい！❤️」ボタンが大きく光り、相手はデートを受け入れる流れになります。

### 📅 3. 最大90日先（3ヶ月）カレンダー＆月別タブ＆3時間枠
- **最大90日（約3ヶ月）先まで予約可能**：日本などで一般的な「1〜2ヶ月先を見据えたデートの約束」にも余裕を持って対応。
- **便利な月別切り替えタブ**：カレンダーの上に月別ボタン（`[ すべて ]` `[ 10月 ]` `[ 11月 ]` `[ 12月 ]`など）があり、ワンタップで目的の月にジャンプできます。
- **正確な3時間枠の指定**：`19:00〜22:00`など3時間の時間帯をプリセットや時間入力フォームから指定可能。「すべての日程にコピー」機能も完備。
- **タイムゾーンの自動判定と固定**：作成者のブラウザのタイムゾーン（日本なら東京時間、ブラジルならブラジリア時間）を自動認識してリンクに固定。相手が言語を切り替えても時間がズレません。
- **Googleカレンダー登録リンク**：確定画面から相手が1タップで自分のGoogleカレンダーに3時間枠・正しいタイムゾーンで登録できます。

### 🟢 4. 作成者ごとの連絡先完全分離（プライバシー保護）
- コード内に個人情報（電話番号やLINE ID）のハードコードは一切ありません。
- 作成者が入力した連絡先（LINE、WhatsApp、Messenger）だけが相手の確定画面に表示されます。入力しなかったSNSのボタンは自動で非表示になります。
- 1タップで相手のメッセージをクリップボードにコピーして連絡できます。

### 🌐 5. 4つの言語にいつでも切り替え可能
- 画面右上のマークから、いつでも言葉を変えられます：
  - 🇯🇵 **日本語** (`ja`)
  - 🇺🇸 **英語** (`en`)
  - 🇧🇷 **ポルトガル語** (`pt`)
  - 🇪🇸 **スペイン語** (`es`)
- 相手のスマホの言語に合わせて自動で表示されます。

### 📊 6. リアルタイム回答ダッシュボード
- 作ったリンクに誰かがアクセスした回数や、「いいえ」から逃げた回数がリアルタイムで見られます。
- 相手が日程を選んで「確定」を押すと、画面を更新しなくてもポンッと画面にお知らせが届きます（WebSocket機能）。

## 🛠️ どうやって作ったの？（技術構成）

このアプリは、シンプルで軽く、そして早く動くように設計されています。

- **バックエンド（サーバー側）**：
  - **Python 3.12**：最新の安定したPythonを使用。
  - **FastAPI**：とても高速でモダンなWebフレームワーク。
  - **Uvicorn**：非同期処理（ASGI）を動かすサーバー。
  - **SQLAlchemy & SQLite**：作ったリンクや回答を保存する軽量データベース。
- **フロントエンド（見た目と動き）**：
  - **HTML5 & Jinja2テンプレート**：サーバーから動的に画面を生成。
  - **Tailwind CSS**：デザインが崩れず、スマホでもパソコンでも綺麗に見えるデザイン。
  - **Vanilla JavaScript（ピュアJavaScript）**：重いライブラリを使わず、軽快に動くアニメーションとクリップボード操作。
  - **Canvas Confetti**：画面いっぱいに紙吹雪を飛ばすお祝いエフェクト。

## 🚀 自分のパソコンで動かす方法

### 必要なもの
- **Python 3.10以上**（Python 3.12をおすすめします）

### 手順

1. **このリポジトリをダウンロード（クローン）します**：
   ```bash
   git clone https://github.com/あなたのユーザー名/zoeira-date-matcher.git
   cd zoeira-date-matcher
   ```

2. **仮想環境（venv）を作って有効化します**：
   ```bash
   # Windowsの場合
   python -m venv venv
   venv\Scripts\activate

   # Mac / Linuxの場合
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **必要なライブラリをインストールします**：
   ```bash
   pip install -r requirements.txt
   ```

4. **アプリを起動します**：
   ```bash
   python run.py
   ```
   ターミナルに表示された **`http://localhost:8050`** をブラウザで開くと、アプリが動きます！

## 🌐 24時間いつでもネット上に公開する方法

自分のパソコンを消しても、友達や好きな人がいつでもアクセスできるようにクラウドサーバー（無料〜低価格）に公開する方法です。

### おすすめ：Render.com を使う方法（簡単・無料枠あり）
1. このプロジェクトをご自身のGitHubアカウントにアップロード（プッシュ）します。
2. [Render.com](https://render.com) にアクセスしてアカウントを作ります（GitHub連携でログインできます）。
3. **「New +」** から **「Web Service」** を選び、GitHubのリポジトリを選択します。
4. 設定を以下のように入力します：
   - **Environment**：`Python`
   - **Build Command**：`pip install -r requirements.txt`
   - **Start Command**：`uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. **「Deploy Web Service」** をクリックします。数分待つと、全世界からアクセスできる無料のURL（例：`https://your-app.onrender.com`）が手に入ります！

### 自宅PCから今すぐ一時的に公開したい場合：Cloudflare Tunnel
パソコンに `cloudflared` がある場合、以下のコマンドを打つだけで無料かつ安全に公開URLが発行されます：
```bash
cloudflared tunnel --url http://localhost:8050
```
